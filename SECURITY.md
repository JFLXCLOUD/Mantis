# Security reporting

Mantis Studio is pre-release software. Only the current development branch is maintained; no production release is available yet.

Please report exploitable SVG/file handling, desktop isolation, device bridge or dependency problems privately through [GitHub's vulnerability reporting form](https://github.com/JFLXCLOUD/Mantis/security/advisories/new). Include the affected commit, Windows version, reproduction steps and expected impact. Use a minimal original sample without personal project data.

Do not put credentials, device addresses/serials, raw Bluetooth captures or private project files in a public issue. Coordinate any sensitive sample through the private report. No response-time guarantee or bounty program is currently offered.

Direct cutting is not implemented. Please use ordinary issues for unsupported features and connection troubleshooting that do not expose a security vulnerability.
