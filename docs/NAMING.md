# Name chosen: Mantis Studio

The user approved **Mantis Studio** on 8 October 2026. The mascot is **Manti**, a friendly praying mantis whose folded angular forearms suggest precise cutting. The mark carries those arms into an M-shaped silhouette.

This replaces the Hopper/grasshopper name. The [approved concept](../assets/brand/concepts/mantis/mantis-concept-board.png), [production kit](BRANDING.md) and archived Hopper assets preserve the design history. The workspace directory and legacy file/storage identifiers remain unchanged for compatibility.

Manti and Mantika were alternate app-name ideas. Mantis Studio was the recommended working name accepted by the user; Manti became the character's name. Name availability has not been assessed.
