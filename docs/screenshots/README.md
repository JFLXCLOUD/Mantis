# Reviewed product screenshots

The editor, object menu, Print Then Cut preparation, dark editor and appearance/update settings screenshots in this directory are reviewed public previews using original/sample artwork. The theme/settings previews were captured from the packaged Windows 0.7.0 app using an isolated profile. Test-generated hardware screenshots and historical local captures are ignored because they can contain device identifiers or private workspace details.

Review each new screenshot before adding it to the `.gitignore` allowlist. Tests may overwrite local screenshots; publication still requires review of the resulting image.

The material-library light/dark and custom-profile screenshots were reviewed from an isolated Windows 0.8.0 package. All names, supplier descriptions and notes are demonstration data; no device or personal project details are shown.
