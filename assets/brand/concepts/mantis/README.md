# Mantis identity exploration

Status: this direction was approved and implemented as Mantis Studio 0.4.0, with Manti as the mascot. See the [production identity kit](../../../../docs/BRANDING.md). The notes below preserve the original exploration brief.

Draft requested 8 October 2026. This explores a new name and praying mantis mascot for Hopper. The current application and approved Hopper assets remain unchanged. These are creative naming candidates; domain, package and trademark availability have not been checked.

## Naming shortlist

| Name | Direction | Tradeoff |
| --- | --- | --- |
| **Mantis Studio** | Clearest connection between the name, mascot and craft-design application. Recommended working name for this visual exploration. | A common animal word; distinctiveness and existing software names need checking before adoption. |
| **Manti** | Short, friendly, easy to use as both app and mascot name. | The insect connection is less immediate without the logo. |
| **Mantika** | A coined mantis-inspired name with a playful craft-brand sound. | Pronunciation is less obvious and it needs an introductory story. |

## Visual direction

A friendly, focused praying mantis with a triangular face, expressive eyes, a slender body and folded forearms. The angular arms suggest careful cutting without giving the character weapons. Keep the forest/sage/ivory palette to maintain continuity with Hopper.

The full mascot can have restrained dimensional shading. The logo should use simple flat geometry. The app icon should reduce to the head and folded arms, with a possible M-shaped silhouette. A full insect illustration will not be legible at tiny Windows icon sizes.

The draft board uses **Mantis Studio** as a working title, with Manti and Mantika shown as alternatives. It is concept art, not a production vector logo or a cut-ready file.

## Adoption after a direction is chosen

- Develop editable SVG lettering, mark, monochrome/reversed variants and small-size icon geometry.
- Produce a transparent mascot and Windows icon exports; check light/dark backgrounds and tiny sizes.
- Update the visible application name and brand kit together.
- Preserve the existing application profile, autosaved artwork, machine preferences and `.hopper` file compatibility. Changing branding should not make projects disappear.
- Keep the Hopper identity archived and document the new asset provenance.

## Generation provenance

The concept uses the built-in image-generation tool, with no competitor artwork as a reference. See [PROMPT.md](PROMPT.md) for the exact prompt. No source code, application identity, project extension or installed app assets were renamed during this exploration.
